# 排期看板功能说明

## 功能概述

在"人力排布工作台"下新增"排期看板" Tab，用甘特图展示不同项目的测试起止日期与排期情况，超期部分使用不同颜色标注，并支持风险提示和详情查看。

## 实施内容

### 一、后端实现

#### 1. 新增 DTO
- **文件**: `backend/src/main/java/com/testscheduling/dto/GanttViewItem.java`
- **字段**:
  - `demandId`: 需求ID
  - `product`: 产品名称
  - `version`: 版本号
  - `versionType`: 版本类型
  - `startDate`/`endDate`: 测试周期
  - `status`: 需求状态
  - `manpowerDemand`: 人力需求
  - `allocatedDays`: 已分配人力
  - `remainingDays`: 剩余缺口
  - `daysToEnd`: 距离结束天数
  - `priority`: 优先级
  - `confidential`: 是否保密
  - `riskScore`: 风险分数（0-100）
  - `riskFactors`: 风险因素列表
  - `progressPercentage`: 进度百分比（基于时间）

#### 2. 新增服务方法
- **文件**: `backend/src/main/java/com/testscheduling/service/ScheduleService.java`
- **方法**: `getGanttView()`
- **功能**:
  - 获取所有 `scheduled` 和 `completed` 状态的需求
  - 计算已分配人力和剩余缺口
  - 计算时间进度百分比
  - 进行风险评估（4个维度）:
    - **超期风险**（40分）: 已超期或剩余时间不足
    - **人力缺口风险**（30分）: 人力缺口比例
    - **优先级风险**（20分）: P0/紧急级别
    - **进度滞后风险**（10分）: 实际进度落后预期进度

#### 3. 新增接口
- **URL**: `GET /api/schedules/gantt-view`
- **Controller**: `ScheduleController.getGanttView()`
- **返回**: `List<GanttViewItem>`

### 二、前端实现

#### 1. 新增页面组件
- **文件**: `src/pages/ScheduleGantt.tsx`
- **功能**:
  - 甘特图展示（自定义实现，未使用第三方库）
  - 产品/状态/时间范围筛选
  - 进度条颜色标识:
    - 🔴 **红色**: 已超期
    - 🟡 **黄色**: 剩余3天内
    - 🟢 **绿色**: 已完成
    - 🔵 **蓝色**: 正常进行中
  - 风险标识和点击交互
  - 风险详情弹窗

#### 2. 集成到工作台
- **文件**: `src/pages/ScheduleWorkbench.tsx`
- **修改**:
  - 引入 `Tabs` 组件
  - 新增 `activeTab` 状态
  - 添加两个 Tab: "排班工作台" 和 "排期看板"
  - 条件渲染对应视图

#### 3. 更新 API 服务
- **文件**: `src/services/api.ts`
- **新增方法**: `getGanttView()`

### 三、权限控制

- 复用现有的 `scheduleManpower` 权限
- 测试经理、资源经理、项目经理可访问
- 在 `ScheduleWorkbench` 页面权限控制下统一管理

## 使用说明

### 1. 访问路径
1. 登录系统
2. 点击左侧菜单"人力排布工作台"
3. 点击顶部 Tab "排期看板"

### 2. 功能操作

#### 筛选功能
- **产品筛选**: 多选下拉框，筛选指定产品
- **状态筛选**: 默认显示"已排期"和"已完成"，可选"待排期"
- **时间范围**: 选择日期范围，只显示该范围内的需求

#### 查看风险
- 风险分数 ≥ 50 的需求，甘特图条上会显示红色警告图标
- 甘特图条边框为红色虚线
- 点击有风险的进度条，弹出风险详情弹窗
- 风险详情包含:
  - 需求基本信息
  - 风险分数
  - 风险因素列表（具体原因）
  - 人力缺口情况

#### 进度理解
- 进度百分比基于**时间进度**计算: `(今天 - 开始日期) / (结束日期 - 开始日期) × 100%`
- 已完成的需求固定显示 100%
- 进度条前半部分为实色，后半部分为半透明，直观显示进度

#### 状态标签
- **已完成**: 绿色标签
- **超期 N 天**: 红色标签
- **剩余 N 天**: 黄色标签（≤3天）
- **进行中**: 蓝色标签

### 3. 颜色含义

| 颜色 | 含义 | 条件 |
|------|------|------|
| 🔴 红色 | 已超期 | `endDate < 今天` 且 `status ≠ completed` |
| 🟡 黄色 | 即将到期 | `endDate - 今天 ≤ 3天` 且 `status ≠ completed` |
| 🟢 绿色 | 已完成 | `status = completed` |
| 🔵 蓝色 | 正常进行中 | 其他情况 |

### 4. 风险评估规则

#### 风险分数（0-100分）
- **≥ 70分**: 高风险（红色）
- **50-69分**: 中风险（黄色）
- **< 50分**: 低风险（绿色）

#### 风险因素
1. **超期风险**（最高40分）
   - 已超期: 40分
   - 3天内到期: 30分

2. **人力缺口风险**（最高30分）
   - 缺口比例 > 30%: 30分
   - 缺口比例 10-30%: 20分
   - 缺口比例 < 10%: 10分

3. **优先级风险**（最高20分）
   - P0/紧急: 20分
   - P1/高: 10分

4. **进度滞后风险**（最高10分）
   - 实际进度落后预期进度 > 20%: 10分

## 注意事项

1. **依赖安装**: 前端组件使用了 Ant Design 内置组件，无需额外安装第三方甘特图库
2. **数据刷新**: 排期看板数据在进入时自动加载，如需刷新请切换 Tab 或刷新页面
3. **时间计算**: 所有时间计算基于服务器时间，确保服务器时间准确
4. **风险评估**: 风险分数是实时计算的，会随着时间推移和排班变化自动更新
5. **兼容性**: 使用标准 CSS 和现代浏览器特性，建议使用 Chrome/Edge/Firefox 最新版本
