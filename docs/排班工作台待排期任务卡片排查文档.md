# 排班工作台 — 待排期任务卡片不显示排查文档

## 问题描述

用 admin 账号登录后，进入「人力排布 → 排班工作台」，左侧「待排期」Tab 显示"暂无待排期需求"，但后端 API 实际返回了 3 条 pending 状态的需求。

## 已完成的排查

### 1. 后端 API 正常

已验证以下 4 个 `ScheduleWorkbench` 依赖的 API 端点，admin 调用均返回 200：

| 端点 | 结果 |
|------|------|
| `GET /api/demands/pending` | 3 条需求，`manpowerFullySatisfied=false` |
| `GET /api/schedules` | 正常（当前 0 条排班） |
| `GET /api/staff` | 5 条人员 |
| `GET /api/daily-statuses` | 正常 |

### 2. admin 权限已补全

**文件**: [src/context/UserRoleContext.tsx:60-72](src/context/UserRoleContext.tsx#L60-L72)

admin 原先缺少排班相关权限，已添加：
- `scheduleManpower`
- `aiRecommendSchedule`
- `manageDailyAvailability`

### 3. 前端筛选逻辑正确

**文件**: [src/pages/workbench/workbenchCalculations.ts:258-277](src/pages/workbench/workbenchCalculations.ts#L258-L277)

`filterPendingDemands` 筛选条件：
```typescript
const needsAllocation = d.manpowerFullySatisfied !== true
  || d.requiresHistoricalClassification === true;
return needsAllocation && matchesTestType;
```

API 返回的 3 条需求均为 `manpowerFullySatisfied=false`，应通过筛选。

### 4. 数据流正常

**文件**: [src/pages/ScheduleWorkbench.tsx:299-358](src/pages/ScheduleWorkbench.tsx#L299-L358)

`refreshAuthoritativeData` → `api.getPendingDemands()` → `setDemands(normalizedDemands)` → 传给 `DemandQueue`。

**文件**: [src/pages/workbench/DemandQueue.tsx:69-72](src/pages/workbench/DemandQueue.tsx#L69-L72)

`pendingDemands` 通过 `useMemo` 从 `filterPendingDemands(demands, ...)` 派生。

### 5. Vite HMR 热更新失败

Vite 日志显示：
```
11:55:19 AM [vite] hmr invalidate /src/context/UserRoleContext.tsx
Could not Fast Refresh ("useUserRole" export is incompatible)
```

权限修改后 HMR 未能热替换，需要用户在浏览器中硬刷新（Cmd+Shift+R）才能生效。

## 待确认事项

1. **用户是否已硬刷新**：HMR 失败后，旧的权限代码仍在浏览器内存中运行，admin 没有 `scheduleManpower` 权限，菜单可能被过滤掉或页面行为异常。

2. **如果硬刷新后仍不显示**，需要排查：
   - 浏览器控制台是否有 JS 报错
   - `DemandQueue` 组件是否收到 `demands` prop（React DevTools 检查）
   - CSS 布局问题：`DemandQueue` 的父容器 `height: 100%` 链是否断裂

3. **CSS 布局风险点**：
   - `ScheduleWorkbench` 根 div: `height: 100%`（依赖父级有确定高度）
   - `Content` 容器: `overflow: auto; flex: 1; minHeight: 0`
   - `DemandQueue` Card: `width: 270; flexShrink: 0`（无显式 height）
